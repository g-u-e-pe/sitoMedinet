# Medinet Website

Benvenuto nel progetto **Medinet Website**! Questo progetto è una piattaforma web sviluppata con React e varie librerie moderne. È progettato per fornire un'esperienza interattiva e visivamente accattivante, integrando funzionalità avanzate come mappe, componenti interattivi e supporto per il design responsivo.

### Browser supportati
Il progetto supporta i seguenti browser secondo la configurazione di `browserslist`:

**Produzione**:
- Browser con >0.2% di utilizzo globale.
- Browser attualmente supportati dai produttori.
- Esclusi: versioni morte e `Opera Mini`.

**Sviluppo**:
- Ultima versione di Chrome.
- Ultima versione di Firefox.
- Ultima versione di Safari.

## Installazione

Per eseguire il progetto in locale, segui questi passaggi:

### Naviga nella cartella del progetto:

cd medinetwebsite
Installa le dipendenze:
bash -> npm install
Avvia il server di sviluppo:
bash -> npm start
Questo avvierà il progetto su localhost, dove potrai visualizzare il sito in modalità di sviluppo.

Uso
Il progetto è costruito utilizzando React e Webpack. Puoi iniziare a lavorare su di esso modificando i componenti in src/components. Il file src/App.js contiene la struttura principale del progetto.

Test
Per eseguire i test del progetto, usa il comando:

bash -> npm test
Build
Per creare una versione di produzione del progetto, esegui:
bash -> npm run build
